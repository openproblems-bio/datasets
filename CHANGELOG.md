# datasets v0.2.0 (unreleased)

* DEPRECATION: The openproblems v1 loaders and workflows (`openproblems_v1`, `openproblems_v1_multimodal`, `process_openproblems_v1`, `process_openproblems_v1_multimodal`) are deprecated. Published benchmark results that use the v1 datasets remain, but no new v1 datasets are built.

* MINOR CHANGE: Bump Viash to 0.9.7.

* MAJOR CHANGE: Split the scRNA-seq workflows into loading and processing. `load_cellxgene_census` and `load_openproblems_op3` (optionally subsample and) write a raw dataset, and `process_scrnaseq` turns any raw dataset into a common dataset with a single normalisation (log CP10k). They replace `process_cellxgene_census` and `process_openproblems_op3`.

* NEW FUNCTIONALITY: `validation/validate_dataset` checks a raw or common dataset against its format in `src/api`. The load and process workflows run it before publishing, so an invalid dataset fails the run.

* MINOR CHANGE: `load_cellxgene_census` requires a dated Census release, since `latest` and `stable` give different datasets over time.

* MAJOR CHANGE: Move to anndata 0.13 (base images v1.3.0), which writes zarr v3 with sharded arrays, so a dataset has far fewer files. `ANNDATA_AUTO_SHARD_ZARR_V3=1` makes the sharding explicit, and the deprecated `ANNDATA_ZARR_WRITE_FORMAT` is dropped. Test resources regenerated.

* BUG FIX: The Census and NeurIPS loaders no longer name the `var` index after the `feature_id` column, which anndata 0.13 refuses to write back after reading. `log_scran_pooling` no longer needs the `anndata` R package, and `atac_tfidf` no longer pins `numpy<2`, which held it on anndata 0.12.

* MINOR CHANGE: Pin BLAS, OpenMP and numba to 4 threads in every Docker image. The PCA (and with it the kNN graph) depended on the number of cores of the machine.

* MAJOR CHANGE: Raw scRNA-seq datasets must have CELLxGENE-style ontology term ids for the assay, cell type, developmental stage, disease, self-reported ethnicity, sex and tissue. The multimodal loaders use a new `file_multimodal_raw` spec, in which these stay optional.

* MAJOR CHANGE: Raw scRNA-seq datasets store the organism per cell in `obs['organism_ontology_term_id']` (required, NCBI Taxonomy) and `obs['organism']`, instead of `uns['dataset_organism']`. The CELLxGENE Census loaders fill it in from `--species` or the source h5ad, and the OP3 loader sets `NCBITaxon:9606`. Multimodal and spatial datasets still use `uns['dataset_organism']`.

* BUG FIX: The loaders store `uns['dataset_reference']` and `uns['dataset_organism']` as lists, as declared in `src/api`, since a dataset can have several references and organisms. The OP3 loader takes both as arguments instead of hardcoding them.

* BUG FIX: `uns['pca_variance']` is declared as an `object` in `file_pca`, since `processors/pca` writes a dict.

* MINOR CHANGE: The OP3 loader adds these ontology term ids, based on its cell type annotation and the donor metadata in GEO.

* MINOR CHANGE: Component tests use the `cxg_mouse_pancreas_atlas` test resources instead of the deprecated `pancreas` ones. Its notebook now keeps every processing step.

* BUG FIX: `processors/pca` stored the explained variance and the variance ratio under each other's name in `uns['pca_variance']`.

* BUG FIX: `processors/svd` gains a `--seed` argument. Its randomized solver gave a different embedding in every run.

* BUG FIX: `processors/subsample` no longer fails when the `--keep_*` filters leave fewer cells than `--n_obs`.

* MINOR CHANGE: Failed Nextflow processes are no longer ignored, so a failing dataset fails the run.

* MAJOR CHANGE: All loaders, components and workflows write AnnData zarr stores instead of h5ad files, and the file formats in `src/api` are now `anndata_zarr`. Every Docker image sets `ANNDATA_ZARR_WRITE_FORMAT=3`. Multimodal datasets are still two AnnData stores, spatial datasets one.

* NEW FUNCTIONALITY: `scripts/lamin/annotate_artifacts.py` annotates dataset artifacts in LaminDB with what the OpenProblems website shows about a dataset: a schema with every slot of the `src/api` file format, the ontology terms in `obs`, the `dataset_*` metadata, the structure of the store, cell counts per category, processing parameters, the modality and references with their DOI. Run it after a workflow published datasets; the test resource notebooks call it for their artifacts and record the workflow parameters on their run.

* MAJOR CHANGE: Test resources are generated by notebooks in `scripts/create_test_resources` and stored as one collection per notebook in the public LaminDB instance `openproblems/data-dev`. CI syncs them with `edaro/viash-actions`. `pancreas.ipynb` replaces `pancreas.sh`.

* MINOR CHANGE: The CELLxGENE immune cell atlas, CELLxGENE mouse pancreas atlas, Visium mouse brain, NeurIPS 2021 bone marrow and sci-CAR cell lines test resources are generated by notebooks too. Their subsampling is now seeded, and the CELLxGENE ones no longer pass cell cycle gene symbols as `keep_features`, which never matched their Ensembl gene ids.

* MINOR CHANGE: The NeurIPS 2022 test resources are generated by a notebook too, from source files now stored in the private LaminDB instance `openproblems/private`. Their descriptions no longer describe the NeurIPS 2021 bone marrow data: they are CD34+ hematopoietic stem and progenitor cells from 4 donors over a 10-day time course.

* MAJOR CHANGE: Remove the `extract_uns_metadata` step and `--output_meta*` outputs from the workflows, as well as the `extract_dataset_info` and `extract_dataset_meta` workflows. Dataset metadata will be stored in LaminDB.

* MINOR CHANGE: Remove the h5ad-only `--output_compression` argument.

* MINOR CHANGE: The openproblems v1 loaders install openproblems v0.8.0 without its pinned 2022-era dependencies and run on `openproblems/base_python:1`, so they write the same zarr format as the other loaders.

* BUG FIX: `processors/subsample` draws with a seeded numpy generator; `--seed` had no effect before.

* BUG FIX: `processors/pca` runs on the features selected by `--input_var_features` (HVGs by default), which it previously ignored. `processors/pca` and `processors/knn` gain a `--seed` argument.

* MINOR CHANGE: Update the `common` submodule, which adds `labels_denbi.config`.

* MINOR CHANGE: Drop the custom `multiple_sep` from the CELLxGENE census loaders and workflow; pass multiple values with `;`.

* MINOR CHANGE: Remove the unused `scripts/run_benchmark` scripts.

* DOCUMENTATION: Cite the published OpenProblems paper.

* BUG FIX: `normalization/l1_sqrt` computes the normalization with scipy instead of the unmaintained `scprep`, which no longer installs.

* BUG FIX: `processors/svd` uses `anndata.read_h5ad()` instead of the removed `anndata.read()`.

* BUG FIX: The openproblems v1 loaders build on Python 3.10 and download without `scprep`'s spoofed user agent, which figshare and GEO refuse.
